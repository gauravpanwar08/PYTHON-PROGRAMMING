# Employee Management System

A practical Employee Management System built with SQLAlchemy Core and SQLite.

## Features

- Department management
- Employee management
- Project management
- Employee-project assignments
- CRUD operations
- JOIN queries
- Search and filtering
- Sorting and pagination
- Aggregation reports
- Subqueries and EXISTS
- CTE
- Window functions
- Transactions
- Raw SQL
- Database inspection

## Technologies

- Python
- SQLAlchemy Core
- SQLite
